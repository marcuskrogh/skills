# Frontend design sample

Calibration pages for the **retro-futuristic** default on
[CONCEPT_FRONTEND](../../skills/concepts/CONCEPT_FRONTEND.md).

## Quay

**Brief.** Harbour log for a small-boat skipper. Audience: the person on the
boat. Job: see the next slack, wind, and tide, then add a short log line.

**Era.** 1972 marine instrument — off-white hull, steel tide window, orange
switch (Rams / Braun Sixtant and Aromaster).

**Signature.** Tide as a steel-window numeric readout. Orange switch on the
log action.

**Type.** Archivo.

Open [index.html](index.html).

## Heating Assistant (dummy panel)

Same dummy as the Heating Assistant ingress panel. Audience: the person running
house heating. Job: see system health and room climate, start or stop, set
targets and comfort bands.

**Era.** 1972 climate instrument — off-white capsules, steel windows, orange
switch.

**Tokens.** Hull `#f0ece4`, ink `#1a1916`, mute `#6a6660`, steel `#c4c9ce`,
steel-deep `#8e959c`, accent `#ef5a11`. Off-white is the body; steel is the
working edge; orange is the control.

**Signature.** Overview: Next Control as a steel-window readout, Start as the
orange switch. Living room: current temperature in a steel window; controls
and schedule in their own blocks.

**Type.** Archivo.

Open [heating-overview.html](heating-overview.html) and
[heating-room.html](heating-room.html). Calibration only — not a product
template.
