# Frontend design sample

Calibration pages for the **warm** default on
[CONCEPT_FRONTEND](../../skills/concepts/CONCEPT_FRONTEND.md).

Heating Assistant is the candidate. These pages restyle the ingress jobs
(overview, Start, room climate, plot) without changing the Heating Assistant
repo.

**Audience.** The person running house heating.

**Job.** See system health and room climate, start or stop, set targets and
comfort bands.

**Tokens.** Hull `#f0ece4`, ink `#1a1916`, mute `#6a6660`, accent `#ef5a11`,
plum `#8b5e83`. Cream is the body; terracotta is the control.

**Signature.** Overview: Next control as a large tabular time, Start as the
terracotta pill. Living room: current temperature as type; a warm time-series
plot on the room page.

**Type.** Archivo.

Open [index.html](index.html) (overview) and
[heating-room.html](heating-room.html). Calibration only — not a product
template.
