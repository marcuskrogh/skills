MPC Controller Parameters

Shared with both planners

Comfort band, electricity price, command smoothing, band-exit penalty, and max compute time. Applied on the next planning cycle after you save.

°C — Half-width of the comfort band around the setpoint.

How strongly a high electricity price pushes the plan toward less electrical heat (0 = ignore price).

Penalty on changing the heater command from one interval to the next.

How hard leaving the comfort band is penalised. Larger values fight harder to stay inside.

s — Wall-clock cap for one planner solve. The solver stops at this limit and keeps the best plan found so far (default 60).

Linear MPC cost weights

Extra terms on the linear quadratic program. The nonlinear planner does not use these.

How hard the linear planner pulls toward the exact setpoint while already inside the band (0 = stay inside the band only).

Penalty on heater command size itself, separate from electricity price.

Extra steadily growing penalty the further outside the band (0 = off).

How strongly the last predicted step should still be near the setpoint (must be at least 1).

Timing

Sample interval and look-ahead. Both planners use the same receding-horizon grid. Changing these rebuilds the planner when you Apply Changes.

s — How often heater commands are applied (default 900 s).

h — How far the plan covers (default 36 h). Must be a whole number of sample intervals.
